# Contributing

**This repository is for feedback, not code.** Pull requests cannot be accepted
here. Use:

- an **issue** for a problem, a data problem, or a feature request,
- a **Discussion** for a question or something to show, or
- a **private report** for a security problem. See [SECURITY.md](SECURITY.md).

You do not need to write code to be useful: a clear reproduction, a confusing
sentence, or a missing unit is worth as much as a patch.

## Ground rules

- Be kind. This is a small project.
- Keep reports focused: one problem per issue.
- Everything here is public. Do not paste private data.
- By posting, you agree your words may be used, with attribution where it
  matters, to improve UnitPad. You keep the copyright to what you wrote.
